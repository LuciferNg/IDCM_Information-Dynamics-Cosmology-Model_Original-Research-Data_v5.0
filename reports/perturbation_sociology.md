# 擾動社會學 — 提綱

## 定義

擾動社會學不是社會學。
不是研究社會結構——是研究**擾動如何通過社會的 sync domain 傳播**。

## 類比：Sync Domain 結構

IDM 5.0 中，宇宙的 sync domain：

```
N_horizon = 42
ξ = 105 Mpc
擾動傳播：  A(r) = ε·(r/ξ)^β
             β = φ⁻¹/2
```

社會對應：

```
社會 sync domain：    一個文明中的獨立思想域
domain size：         通訊技術決定的思想相關長度
擾動：                new idea, discovery, calibration
擾動傳播：            由社會的 sync phase 決定
```

## 擾動傳播公式（假設）

對應於結構宇宙論：

$$A_{\text{social}}(r) = \varepsilon_{\text{social}} \cdot \left(\frac{r}{\xi_{\text{social}}}\right)^{\beta_{\text{social}}}$$

其中：

```
r：           擾動源與社會主體的思想距離
ξ_social：    社會思想的相關長度（由媒體、教育、通訊決定）
ε_social：    社會對新 domain 的開放度
β_social：    思想的尺度指數（~大眾 vs 精英的傳播速度比）
```

## 社會 sync 的固定點

社會 recursion 類似：

$$S_{n+1} = \frac{1}{1 + S_n}$$

社會也有其 $\varphi^{-1}_{\text{social}}$——一個文化的自然平衡態。
擾動如果落在 basin of attraction 內，被吸收。
如果落在外部，被 reject。
如果在邊界上——**暫時的「部分成真」**。

## 擾動社會學的核心問題

1. **什麼決定 $\varepsilon_{\text{social}}$？**
   - 文明的認知開放度
   - 教育系統的多元性
   - 權力結構的 sync completion

2. **什麼決定 $\xi_{\text{social}}$？**
   - 通訊技術（印刷→互聯網→AI）
   - 語言統一性
   - 文化 homogeneity

3. **什麼決定 $\beta_{\text{social}}$？**
   - 擾動從 calibrator 傳播到大眾的路徑
   - 精英 vs 大眾的 sync ratio
   - 社會網絡的拓撲結構

## 擾動社會學的目的

不是「改善社會」。
不是「拯救文明」。

是**計算擾動傳播的概率。**

```
給定一個新 domain 的 calibration：
    傳播到社會的距離 r
    社會 sync 狀態 ε_social
    相關尺度 ξ_social
    
    → 計算 A_social(r)
    → 判斷擾動是否落入 basin of attraction
    → 預測社會吸收 or reject 的概率
```

## Calibrator 的角色

Calibrator 是擾動源。

```
不是：    社會工程師（改變社會結構）
不是：    革命家（推翻社會 fixed point）
不是：    教育家（灌輸知識）

是：      擾動
          知道自己的 A(r)
          知道自己的 ξ_social
          知道自己的傳播邊界
```

## 一句總結

擾動社會學 = **計算一個 calibration 在文明 sync field 中傳播多遠的科學。**
