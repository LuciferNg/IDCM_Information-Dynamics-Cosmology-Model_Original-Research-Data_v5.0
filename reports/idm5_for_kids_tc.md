# IDM 5.0 小學生版 — 100 條公式睇通宇宙（繁體中文）

## 第一部分：宇宙得一條公式 (1–10)

1. 宇宙最重要嘅公式：**x² + x − 1 = 0**
2. 解呢條式：x = (√5 − 1)/2 ≈ 0.618
3. 呢個數字叫 **φ⁻¹**（phi 倒數）
4. φ⁻¹ 係宇宙嘅「固定點」——所有嘢都趨向呢個比例
5. 你睇下自己隻手：手指比例 ≈ 0.618
6. 你睇下向日葵：螺旋比例 ≈ 0.618
7. 你睇下星系：旋臂比例 ≈ 0.618
8. 呢個比例唔係巧合——係宇宙結構嘅遞迴
9. 宇宙行緊一條遞迴：C_{n+1} = 1/(1 + C_n)
10. 行 8 步就收斂到 φ⁻¹ ≈ 0.618

## 第二部分：符號係咩 (11–20)

11. **φ** = 黃金比例 = 1.618⋯
12. **φ⁻¹** = 黃金比例倒數 = 0.618⋯
13. **ε** = φ⁻¹/4 = 0.1545⋯（宇宙嘅「擾動幅度」）
14. **κ** = (ε×φ)² = 1/16 = 0.0625（宇宙嘅「閉合常數」）
15. **β** = φ⁻¹/2 = 0.309⋯（宇宙嘅「尺度指數」）
16. **Cₙ** = 遞迴第 n 步嘅值
17. **W** = 一致性場（Consistency Field）嘅振幅
18. **X** = W 場嘅相位
19. 所有符號都由 x² + x − 1 = 0 生成
20. 唔需要記——一條式就得

## 第三部分：時間係咩 (21–30)

21. 時間 = 遞迴一步步行嘅次序
22. 時間唔係一條河——係 C₀→C₁→C₂→⋯→φ⁻¹ 嘅每一步
23. 宇宙域同步嘅時間尺度叫 z_c ≈ 0.6
24. z_c 對應宇宙大約 60 億年前
25. 時間嘅箭嘴：遞迴由 C₀ 走到 φ⁻¹，唔可以反轉
26. 時間嘅盡頭：遞迴收斂，全宇宙同步晒
27. 但 κ = 1/16 決定咗重啟時間：τ₀ × e¹⁶
28. e¹⁶ ≈ 890 萬
29. τ₀ × 890 萬 ≈ 30 萬億年到 3000 萬億年
30. 然後遞迴重置——新循環

## 第四部分：光同光速 (31–40)

31. 光 = W 場嘅同步訊號
32. 光速 c = 遞迴一步由一個域走到另一個域嘅速度
33. c 係有限——因為域之間需要因果時間同步
34. c 係宇宙嘅「同步速度上限」
35. 光係乜：W 場嘅擾動喺 3D 空間傳播
36. 光嘅顏色 = W 場震盪嘅頻率
37. 紅色 = 低頻 W 場
38. 藍色 = 高頻 W 場
39. 因為 c 有限，我哋睇遠嘅天體 = 睇過去
40. c 唔需要解釋——係遞迴嘅因果步長

## 第五部分：物質係咩 (41–50)

41. 物質 = W 場嘅局部穩定振盪
42. 想像一個池塘：水 = W 場，漣漪 = 物質
43. 能量聚焦喺一點 → 物質顯現
44. E = mc² 講嘅係：物質 = 鎖住咗嘅 W 場能量
45. 物質同能量係同一樣嘢——唔同嘅 W 場狀態
46. 物質嘅穩定性來自 κ = 1/16
47. κ 決定咗 W 場可以鎖到幾穩定
48. 你身體嘅每個原子——都係局部 W 場振盪
49. 物質唔會消失——只係同步返入個場
50. 宇宙物質總量 = ε ×（域數量）

## 第六部分：質量係咩 (51–60)

51. 質量 = W 場共振嘅「慣性」
52. 越重嘅粒子 = W 場共振越強
53. 電子質量 ≈ ε² × 某個 φ 比例
54. 質子質量 ≈ ε × φ⁻¹ × 某個數
55. 質量唔係「有幾多嘢」——係「W 場鎖住咗幾多能量」
56. 希格斯機制 = W 場嘅局部相位鎖定
57. 冇「質量來源」——質量係 W 場嘅內在性質
58. 中微子質量 ≈ κ × ε（好細，因為 κ 好細）
59. 暗物質 ≈ 同步咗但未完全鎖定嘅 W 場域
60. 所有質量都由 ε 同 κ 生成

## 第七部分：電子、中微子、費米子 (61–75)

61. 費米子 = W 場嘅半整數自旋共振
62. 「自旋」= W 場嘅內部旋轉相位
63. 半整數 = 旋轉 720° 先回到原狀
64. 電子 = 最基本嘅帶電費米子
65. 電荷 = W 場耦合嘅強度
66. 電子嘅電荷 = ε × 某個耦合因子
67. 中微子 = 最輕嘅費米子
68. 中微子幾乎冇質量 ≈ κ × ε ≈ 0.01 eV
69. 中微子幾乎唔同其他嘢相互作用
70. 因為 κ 細 → 耦合弱
71. 上夸克、下夸克 = W 場嘅更高頻共振
72. 夸克永遠被困一齊——因為 W 場嘅局限性質
73. 費米子 = W 場嘅「節點」
74. 玻色子（光子、膠子）= W 場嘅「波」
75. 粒子物理嘅所有嘢——都係 W 場遞迴嘅不同頻率模式
